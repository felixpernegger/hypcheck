# Workspace: the Lean 4 core library (Init, Std, Lean, Lake)

Hypothesis analysis of the lean4 repository at commit `a2ec8251`. **Fully decided**; results in `Results.md`,
method in `../../Methods.md`, library defects in `Findings.md`. Run every command from this directory.

The lean4 checkout is analysis-only: never edit or commit there. Building it is fine
(`make -j$(nproc) -C build/release`); never delete its build directories without asking.

| `certs/` | Swap certificates: `certs/platform/` (183 rows, checker output in `certs/platform/out/`), `certs/test/`, `certs/lake/` (not certifiable) |

| `seeds/` | The hand-written counterexamples `scripts/models.txt` was extracted from |

Proof file names in `checks/`: `Probe<k>Hand.lean` random-row agent probe; `W<w>c<c>Hand.lean` agent wave w, cluster
c; `Stem<k>Hand.lean` stem clusters (one lemma stem across many wrapper types); `DepStd*` generated by `refute_dep`;
`ChainProofs*` transitive necessity; the other hand files are named after their topic.

## Tools

All Lean tools run with the lean4 repo's own stage1 (not the elan `lean`): set `LEAN4_DIR` to the checkout
(required; no default) or `LEAN` to the binary; Lean scripts use `LEAN_SYSROOT` or `getBuildDir`.

| Script | Use |
|---|---|
| `scripts/HypCheck.lean`, `scripts/run.sh` | The mechanical tool and its memory-capped multi-worker driver: `cd scripts && ./run.sh N OUT.jsonl --module Init [options]` (writes `OUT.jsonl`, `OUT.log`, `OUT.proofs/`) |
| `scripts/models.txt`, `scripts/models_grind.txt`, `scripts/models_lawful.txt` | Hand-made models for `--models` (the first two are symlinks into `../../kit/`) |
| `scripts/PropParams.lean` | Lists theorems with Prop parameters |
| `scripts/Unused.lean`, `UnusedTrans.lean`, `UnusedEmit.lean`, `unused_proofs.py`, `InstDerivable.lean`, `derive_proofs.py`, `NecTrans.lean`, `Twins.lean`, `chain_proofs.py`, `flow/` | Structural detectors and their proof generators; `flow/round.sh K` runs one transitive-necessity round over Std |
| `scripts/priv/` | Private-aware detector variants and `compile_priv.py` (compiles private proofs per module) |
| `scripts/check_hand.py HAND.lean VERDICTS.jsonl` | **Verify a hand file** (statements against `T'`/`¬T'`/`¬∀ indep, Hᵢ`, coverage; `HANDCHECK_AXIOMS=1` for the axiom check). Required before every merge |
| `scripts/merge_hand.py [--std] RUN CLUSTER [FOUND_BY]` | Merge checked verdicts (and `CLUSTER_independent.jsonl`) into `results/` |
| `scripts/recheck_proofs.sh` | Recompile every stored proof file (after a stage1 rebuild); output in `runs/recheck_proofs/` (created by the script) |
| `scripts/audit_proofs.py run OUTDIR` / `report OUTDIR` | Full row-to-proof audit (~2.5 h on 3 lanes) |
| `scripts/swapcheck.sh CERT.lean` | Check a swap certificate; `gen_platform_certs.py`, `platform_cert_summary.py`, `set_provably_independent.py` for the platform rows |
| `scripts/reproof_gen.py`, `reproof_run.py`, `ReproofCheck.lean` | Reproof experiment |
| `scripts/lean.sh` | Stage1 Lean in a memory-capped scope (`MEM`, `TMO`) |

Main `HypCheck.lean` options: `--module M` / `--ns N` (selection), `--import M`, `--models FILE`, `--recheck FILE`
(counterexample search only, for listed rows), `--redo FILE` (also removal, seeded with recorded witnesses),
`--skip FILE` (resume), `--only-private`, `--include-internal`, `--hb`, `--cex-hb`, `--cex-time`, `--cex-cap`,
`--proofs FILE` (always set by `run.sh`). Stored proofs are named `HypCheckProof.T.h<i>`; a verdict with
`proof_ok: false` is unconfirmed.

## Pitfalls

- **Memory.** Never start several Lean processes without a cap: unbounded parallel runs can freeze the machine.
  `run.sh` runs all workers in one systemd scope (`MemoryMax` = min(60% RAM, available − 2.5 GB), no swap,
  `OOMPolicy=continue`) and restarts a killed worker. Init.Grind theorems need ~2 GB per worker: 2–3 workers there.
- `run.sh` writes `OUT.jsonl` only when all workers have exited; to stop but keep finished theorems, kill the `lean`
  workers (not `run.sh`) and resume with `--skip`.
- Scripts run via `lean --run` need `unsafe def main`, `enableInitializersExecution` and `initSearchPath`.
- Heartbeat timeouts are runtime exceptions: use `tryCatchRuntimeEx` and `withCurrHeartbeats`.
- Build goals in an empty local context, or tactics see the dropped hypothesis.
- `pkill -f PATTERN` also kills the shell whose command line contains the pattern; match with
  `ps -eo args | grep "^<binary>"`.
- If stage1 is older than the source, line numbers and statements are off: rebuild it first.
- Model lines may contain ` := ` inside the term: split at the first one only.
- Hand files: put only theorem names in backticks in the comment above a declaration (`check_hand.py` reads them);
  state dependent refutations with the full `indep% T i`.
