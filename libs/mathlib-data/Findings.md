# Findings: Mathlib.Data

Removable hypotheses worth an upstream change, all kernel-checked. A tag such as `(W1c0)` names the proof file `checks/W1c0Hand.lean`; "Probe" means `checks/Probe1Hand.lean`/`Probe2Hand.lean`.
